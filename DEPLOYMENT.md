# Nexyrium portfolio deployment

This is a static website. No framework build step is required.

## Vercel settings
- Framework preset: Other
- Root directory: .
- Build command: leave empty
- Output directory: .
- Install command: leave empty

Import Ashutosh0540/nexyrium-portfolio into Vercel, deploy, then add nexyrium.in and www.nexyrium.in in the Vercel Domains settings. Follow the exact DNS records Vercel displays at the domain registrar; do not replace existing DNS records before reviewing them.
