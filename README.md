# Nexyrium — Interactive Digital Work Showcase

A responsive, static portfolio showroom built with vanilla JavaScript and CSS. It includes 21 project entries, category filters, accessible project cards, full-screen project exploration, live website iframe previews with external-link fallbacks, app mockups, and keyboard navigation.

## Run locally
```bash
npm run start
```
Open http://localhost:5173. Python 3 is required for the local preview server.

## Deploy to Vercel
Import this GitHub repository in Vercel. Select **Other** as the framework preset, leave the build and install commands empty, and set the output directory to `.`. The site is static and requires no compilation.

## Content integrity
- Some public app imagery is referenced from Google Play's image CDN rather than stored in this repository.
- Verify project ownership and obtain approval for images before public launch.
- Do not publish unverified claims about technologies, performance, or business outcomes.
- Some sites block iframe previews; open their original URL from the project detail view.
